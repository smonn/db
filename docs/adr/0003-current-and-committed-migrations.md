# Current and Committed migrations, after Graphile Migrate

Migrations follow Graphile Migrate's model rather than Drizzle's: one Current migration under active iteration, applied to the Dev database on every change, then committed into an immutable, forward-only history. The Current migration is generated by diffing the Definition against a Shadow database that replays the Committed migrations, and it stays hand-editable; once edited, regeneration stops and shows the diff instead of overwriting. Replaying real SQL beats Drizzle's JSON snapshots, which drift from hand-edited SQL and have broken across releases.

## Considered Options

- **Snapshot diff (Drizzle)**: works offline, but the snapshot is a second history that drifts from the SQL.
- **Hand-written only (Graphile Migrate)**: no generation, which wastes the Definition.
- **Down migrations**: rejected; they are rarely tested and often lossy. Undo with a new forward migration, or reset the Dev database.
